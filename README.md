# DNA Sequence Analyzer

A beginner bioinformatics project built using Python.

## Features

* Counts A, T, G, and C nucleotides
* Calculates GC Content
* Determines DNA sequence length
* Validates DNA input

## Technologies Used

* Python

## Example

Input:

ATGCGATCG

Output:

Length: 9
A: 2
T: 2
G: 3
C: 2
GC Content: 55.56%
